# 不全书搜索

按本手册逐步执行，每一步都是确定动作，无需现场探索。

## 数据源

- 固定路径：`/workspace/data/DND5e_chm`
- 只读查询。该目录为嵌套 git 仓库，已在主仓库 .gitignore 中排除，禁止向其中写入。
- 若目录不存在：执行 `git clone --depth 1 https://github.com/DND5eChm/DND5e_chm /workspace/data/DND5e_chm`（约 1 分钟）。

## 关键陷阱：文件编码为 GBK

本仓库多数中文 HTML 文件是 **GBK/gb2312 编码**，直接 `grep "中文"` 会因字节序列不匹配而漏检。所有中文搜索必须走下面的双通道流程。

## 标准查询流程

### 第 1 步：双通道定位文件

先 UTF-8 直搜，再 GBK 转码搜，两者结果取并集：

```bash
# 通道 A：UTF-8 文件直搜
grep -rl "查询词" /workspace/data/DND5e_chm 2>/dev/null

# 通道 B：GBK 文件搜索（必须转码后再搜）
GBK_Q=$(printf '查询词' | iconv -f UTF-8 -t GBK)
grep -rl "$GBK_Q" /workspace/data/DND5e_chm 2>/dev/null
```

命中文件注意 grep 报 `binary file matches` 的情况——那通常是 GBK 文件被通道 A 的英文/拼音关键词命中，仍属有效命中。

### 第 2 步：转码读取命中文件

按相关性选 1~2 个最像「数据正文」的文件（路径含 法术详述/职业/怪物/装备 的优先），先转码再读取：

```bash
iconv -f GBK -t UTF-8 "<命中文件>" 2>/dev/null | grep -A 8 "条目标题"
```

- 搜索词带上 `｜`（全角竖线）可精确命中条目标题行，如 `"不谐低语｜"`。
- 需要看更多上下文就加大 `-A` 的数值，或用 Read 读转码后的临时输出。
- GBK 转码失败的文件（报 `cannot convert`）改试 `-f GB18030`。

### 第 3 步：按模式输出

输出分两种模式，定义与示例见 `EXAMPLE.md`：

- **概要模式**（默认）：按下方模板提取关键字段输出概要
- **原文模式**：用户要求「完整原文/逐字/不要省略」，或数据将用于录入项目时——逐字呈现条目原文，标注书源与文件路径

**法术概要模板**（从 HTML 条目中提取对应字段）：

```
名称：不谐低语｜Dissonant Whispers
环阶与学派：一环 惑控
职业：吟游诗人
施法时间：1 动作
施法距离：60 尺
成分：V
持续时间：立即
效果描述：（正文原文）
升环施法：（如有）
```

**其他类别**（职业/子职业/装备/怪物/专长）：提取条目名称、所属书源、正文关键数值与描述，保留原文措辞。

## 兜底策略

1. 双通道均无命中 → 用**英文名**重搜（如 `Dissonant`），仓库中 `<H4 id="Dissonant_Whispers">` 这类 HTML 锚点是可靠的英文索引。
2. 英文也无命中 → 该条目可能不在本仓库书源中，或用户用了非标准译名。列出书源目录让用户确认，然后按书源浏览：

```bash
ls /workspace/data/DND5e_chm/            # 69 个书源顶层
ls /workspace/data/DND5e_chm/<书源>/      # 该书源章节结构
```

3. 同一条目命中多个书源 → 以**英文名对齐**判断是否同一法术（不同书源译名可能不同，如 2014 PHB 与 2024 PHB）。默认以《玩家手册》为准，其余书源标注出处。

## 书源导航速查

| 内容 | 优先查看 |
|------|---------|
| 法术（2014） | `玩家手册/魔法/法术详述/<环阶>.html`（一环~九环、戏法） |
| 法术（2024） | `玩家手册2024/法术详述/` |

| 怪物 | 各书源 `生物/` 目录、`多元宇宙的怪物/` |
| 装备 | `玩家手册/装备/` 或书源内 `装备` 目录 |
| 速查表 | `速查/` |

## 执行约束

- 全程零 npm 依赖、零脚本执行：只用 grep / iconv / ls / Read。
- 引用规则原文时保留书源出处，便于用户核对版本差异。
- 数据冲突时（如 2014 与 2024 版描述不同）：并列展示两版并标明书源，由用户裁决。

## 出口路由

- 检索结果将用于**生成流程 / DSL / 节点图 / 控制台代码**时：改用 `skills/法术流程流水线/SKILL.md`，由其编排本 skill（强制原文模式 + 法术库绑定确认），本 skill 保留为纯检索工具。**由流水线调用时只执行本文档「标准查询流程」三步，不读兜底策略与书源导航的完整展开——按流水线 §0.5 定级决定是否需要检索兜底。**
- 仅查规则原文、核对数值：留在本 skill，走完即止。
