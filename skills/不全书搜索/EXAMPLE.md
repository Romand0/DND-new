# 不全书搜索输出示例

本文件演示技能的两种输出模式。查询流程见 `SKILL.md`，本文只约定「查到之后怎么呈现」。

## 模式选择规则

| 模式 | 触发条件 | 行为 |
|------|---------|------|
| **概要模式**（默认） | 用户未指定输出方式 | 按固定模板提取关键字段，输出概要 |
| **原文模式** | 用户要求「完整原文」「逐字」「不要省略」；或数据将用于录入项目（如写入 `spells.json`）需要精确措辞时 | 逐字保留数据源条目原文，无省略、无改写，标注书源出处 |

---

## 模式一：原文模式

以查询「不谐低语」为例。执行 SKILL.md 三步流程命中 `玩家手册/魔法/法术详述/一环.html` 后，转码读取该条目并逐字呈现：

**出处**：《玩家手册》→ `玩家手册/魔法/法术详述/一环.html`（GBK 编码，已转码）

> #### 不谐低语｜Dissonant Whispers
>
> 一环 惑控（吟游诗人）
>
> **施法时间：** 1 动作
> **施法距离：** 60 尺
> **法术成分：** V
> **持续时间：** 立即
>
> 你指定一个施法距离内能够听到你声音的生物，并对其说出只有他能听到的不谐低语，使其受强烈的痛苦折磨。目标必须进行一次感知豁免。豁免失败则受到 3d6 点心灵伤害，并立即执行反应往远离你的方向移动其速度所允许的距离。该生物不会进入明显危险的地域，如火堆或陷坑。豁免成功则伤害减半，且不会执行远离的反应。陷入耳聋状态的目标，进行该豁免时直接判定为成功。
>
> **升环施法。** 使用二环或更高法术位施展该法术，你使用的法术位每比一环高一环，伤害就提高 1d6。

原文模式约束：

- 条目正文逐字保留，包括标点与分段；HTML 标签转为 Markdown 后，字段名（施法时间/施法距离/法术成分/持续时间/升环施法）保持数据源原词
- 必须标注书源与文件路径，便于用户核对
- 同一条目命中多个书源（如 2014 PHB 与 2024 PHB 描述不同）时，逐个完整呈现并各自标注书源

## 模式二：概要模式

同一查询「不谐低语」，概要模式输出：

| 字段 | 内容 |
|------|------|
| 名称 | 不谐低语｜Dissonant Whispers |
| 环阶与学派 | 一环 惑控 |
| 职业 | 吟游诗人 |
| 施法时间 | 1 动作 |
| 施法距离 | 60 尺 |
| 成分 | V |
| 持续时间 | 立即 |
| 效果概要 | 目标进行感知豁免：失败受 3d6 心灵伤害，并以反应向远离施法者方向移动；成功伤害减半且不移动；耳聋目标豁免自动成功 |
| 升环施法 | 每高一环伤害 +1d6 |
| 书源 | 玩家手册 |

概要模式约束：

- 字段名与取值必须来自数据源原文，允许压缩叙述、禁止改写数值
- 「效果概要」为提炼后的短句，完整措辞以原文模式为准
- 多书源冲突时并列展示差异字段并标明书源，由用户裁决

## 其他类别的模式应用

职业、子职业、装备、怪物、专长查询遵循同一套模式：

- 原文模式：完整呈现条目描述、数值表、特性列表，标注书源
- 概要模式：提取名称、类别、关键数值（如生命骰/主属性/伤害骰/价格）、一句描述

示例：查询「长剑」（概要模式）→ 名称：长剑｜Longsword；类别：军用近战武器；价格 15 gp；伤害 1d8 挥砍；属性：灵巧、 versatile（两用）；书源：玩家手册。原文模式下则完整呈现该条目全部属性描述文字。
