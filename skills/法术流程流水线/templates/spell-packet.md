# 法术原文包模板

> 阶段 1 的产出、阶段 3 的输入（法术流程流水线版块 2.1）。逐字保留原文措辞，缺失字段写「原文未给出」并同步记入待裁决项，禁止臆造。

```markdown
# 法术原文包：<中文名>｜<English Name>

## 元数据
- 书源：<玩家手册 2014 / 玩家手册 2024 / 塔莎的万事坩埚 / ...>
- 文件路径：<如 玩家手册/魔法/法术详述/三环.html>
- 环阶与学派：<如 三环 塑能>
- 职业：<法术职业列表>
- spellId：<已入库 id | UNBOUND>

## 原文字段（逐字保留）
- 施法时间：
- 施法距离：
- 成分：（V/S/M 及材料成分原文）
- 持续时间：（含「专注」标注）
- 效果描述：（正文原文，含全部骰子表达式与豁免描述）
- 升环施法：（原文原文；无则写「无」）

## 待裁决项
- <多书源差异 / 译名歧义 / 数值存疑；无则写「无」>
```

## 填写要点

1. **原文模式强制**：本模板用于录入流程生成，按不全书搜索「第 3 步」的原文模式逐字摘录，概要模式禁止。
2. **spellId 查询**：`spellStore.getByName`（本地）+ 云端法术库；均未命中写 `UNBOUND`——此时流水线阻断（版块 2.2），原文包保留待复用。
3. **骰子表达式**：保留原始写法（`8d6`、`3d8+5`），禁止展开为期望值（流程生成器 §1.2）。
4. **专注标注**：持续时间含「专注」字样时原文照抄并加粗，阶段 4 将据此决定是否引入 `concentration_check`。
