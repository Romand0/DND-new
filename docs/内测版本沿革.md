## 内测 v0.1 — 起源与三库战斗底座（2026-06-27 ~ 08-19）

- 2026-06-27 项目初始化，`characterStore.ts` 与首批数据层文件创建
- 装备库 / 法术库 / 角色卡三库成形，确立「装备库模板 → 角色背包实例（childId）→ 战斗变更漏斗（EquipmentChanges）」三层装备身份模型
- 战斗会话主线：先攻、突袭、回合推进、放映回溯（快照还原）、战斗沙盘（切比雪夫网格、双指缩放、长按白圈拾取）
- 账号体系：JWT 登录注册、会话表、R2 头像上传（migrations 0001~0003）；本地 localStorage + 发布订阅 store 模式与云端 D1 双向同步
- FlowEditor 初版与节点级法术绑定（推断：2026-08-20 前后绑定机制已存在并被重构升级）

## 内测 v0.2 — 流程编辑器攻坚与数据层重构（2026-08-20 ~ 08-31）

- 修复 Flow 草稿 LocalStorage 膨胀漏洞与草稿查找链路断裂（8-31）

## 内测 v0.5 — 规格化迭代开局（2026-10-18 ~ 10-24）

- 本期起功能开发转入规格文档制度（`.monkeycode/specs/` 立项、分期交付、探针验收）
- 法术流程流水线（spell-flow-pipeline）：「不全书搜索」与「流程生成器」协同，法术名入口 → 原文检索 → 文本转 DSL → 可用 FlowDefinition；DSL 9 种节点 / 6 种触发边，流程发布表与草稿表（migrations 0004_flows、0005_flow_drafts）
- 战斗施法步骤原子化（combat-cast-steps）：五步状态机（前置检查 → 目标确认 → 检定 → 效果结算 → 收尾），为流程引擎驱动战斗施法预埋契约
- NPC 模板地基（npc-template-foundation）：怪物图鉴 2014 解析器 → 421 条种子 → NpcTemplate 类型完善与图鉴表（migration 0008）
- 角色选项库（migration 0004_character_options）、账号-角色卡绑定（每账号至多 3 张，migration 0006）、法术-流程绑定落库（migration 0007）
- 试验场（proving-grounds）：影子角色卡人偶即开即用、全库调用、实时生效数值仪表盘

## 内测 v0.6 — 团组体系与前厅世界（2026-11-01 ~ 11-03）

- 团组（campaign-group）：顶层组织单元，聚合成员/角色卡/规则书集/战斗/宝藏/剧情笔记；出版物条目保持团组存储之外（migrations 0011、0012 存量迁入默认团组）
- 前厅与团组内两个世界（outside-campaign-world）：未登录访客浏览出版物四库，无团组用户主页（团组列表/创建/加入），在团用户快捷进入
- 站点管理员独立于游戏身份（migration 0009，users.is_admin）与存量来源字段回填（migration 0010）
- 沙盘移动引擎（battleground-movement-engine）：8 方位判定体系、定向强制位移双入口、禁行格绕行路线规划（battleGeometry）

## 内测 v0.7 — 战斗结算与圆桌信箱（2026-11-05 ~ 11-09）

- 备战槽重构（readied-hands）：角色卡手持属性改为备战槽（readiedLeft/Right），战斗层手持迁至参战者、随放映快照回溯
- 战斗结算（combat-settlement）：战斗全程角色卡只读，结束时装备/法术位/HP/持续状态统一并入角色卡并封存记录
- 圆桌·通用检定（round-table-checks）：D1 消息信箱（migration 0013），确立「消息不可变、游标增量、type 开放」三原则；DM 定向抛送检定，玩家结果经特性引擎加工回传
- 圆桌枢纽规划定稿（round-table-hub-roadmap）：收编 M-R1 通用检定、M-R2 战斗观战抛送里程碑，任务管理与全站搜索立项
- 三宝书图鉴种子入库（github-seed-library）：玩家手册/城主指南/怪物图鉴种子分片硬编码进仓库，开箱即用、版本化刷新

## 内测 v0.8 — 玩家自助回路与规则引擎族（2026-11-11 起，进行中）

- 角色卡玩家变更回路（character-change-review）：玩家提交整卡快照申请，DM 审批落卡或驳回附理由；一卡一 pending 由数据库部分唯一索引兜底（migration 0014）
- 体系视图（system-view）：职业玩法体系（超魔法/魔能祈唤/引导神力等容器与成员条目）在角色卡聚合分页呈现
- 角色全周期日志（migrations 0015、0016）：物资钱币/法术/角色成长分类记账
- 通用反应引擎（reaction-engine，日期未记录，推断 11 月上中旬）：借机攻击迁入数据声明式反应机制；P1 事件抽象 → P2 攻击目标反应窗口 + 法术反应声明 → P3 damage_taken / spell_cast 插桩与玩家提交窗口化，P3 已合并
- 被动战斗规则引擎（passive-engine）：七类口径冻结——豁免优劣势（含灵光）/ 伤害抗性免疫 / 无甲防御 AC / 速度修正 / 被动检定三件套 / 黑暗视觉 / 先攻优劣势
- 主动技能池引擎 P1（active-skills-engine）：特性池公式（fixed/classLevel/abilityMod/levelTiers）+ featureUses 资源漏斗 + 结算并入 + 放映快照 + 长休短休重置 + 种子标注；P2（状态/反应/玩家端自助）与 P3（damage/attack-rider 通道）规划中
