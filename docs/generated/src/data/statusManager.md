# src/data/statusManager.ts

## 功能概述
该文件定义了一个状态管理器，负责管理游戏中的状态实例。它负责状态实例的生命周期管理，包括状态的声明开始、声明结束、效果查询和回合推进。状态管理器是游戏运行时状态管理的关键组件，确保状态能够正确地被创建、更新和销毁。

## 主要导出/接口

### 导出类型

- `StatusInstance`: 状态实例类型，包含状态实例的详细信息。
- `StatusDefinition`: 状态定义类型，包含状态的定义信息。
- `StatusManager`: 状态管理器类型，包含管理状态实例的方法。
- `StatusScope`: 状态作用域类型，定义状态的作用范围。
- `Effect`: 效果类型，定义状态的效果。
- `EffectType`: 效果类型枚举，定义不同类型的效果。
- `StatusChangeEvent`: 状态变化事件类型，定义状态变化时触发的事件。
- `StatusChangeListener`: 状态变化监听器类型，定义监听状态变化的对象。

### 导出函数

- `createStatusManager()`: 创建一个新的状态管理器实例。

### 导出常量

- `globalStatusManager`: 全局状态管理器单例。

## 核心实现说明
状态管理器通过维护一个状态实例存储和监听器列表来管理状态。它提供了声明状态开始、声明状态结束、查询状态效果、推进回合和清理过期状态的方法。

状态管理器与状态库（`statusLibrary`）紧密相关，用于获取状态定义。状态管理器通过监听器机制来通知外部组件状态的变化。

状态管理器被游戏的其他模块引用，用于创建、查询和管理状态实例，确保游戏逻辑能够正确地响应状态变化。

## 注意事项或使用方式
- 使用 `createStatusManager()` 创建状态管理器实例。
- 使用 `declareStart()` 方法声明状态开始，需要提供状态定义 ID、目标 ID、作用域和战斗 ID（可选）。
- 使用 `declareEnd()` 方法声明状态结束，需要提供状态实例 ID。
- 使用 `getActiveStatuses()` 方法获取活动状态列表。
- 使用 `hasEffect()` 方法检查目标是否有特定类型的效果。
- 使用 `getEffects()` 方法获取目标的所有效果。
- 使用 `advanceRound()` 方法推进回合，处理状态衰减。
- 使用 `cleanupExpired()` 方法清理过期状态。
