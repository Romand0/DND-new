# src/data/editorState.ts

## 功能概述

该文件定义了全局编辑窗口状态，用于控制如 SyncButton 等浮动元素的显示。它负责跟踪编辑窗口的开启和关闭状态，并提供订阅状态变化的能力。

## 主要导出/接口

- `editorState`: 对象，包含以下方法：
  - `open()`: 打开编辑窗口，增加计数。
  - `close()`: 关闭编辑窗口，减少计数（不会小于0）。
  - `get()`: 返回编辑窗口是否开启的布尔值。
  - `subscribe(fn: () => void): () => void`: 订阅状态变化，返回一个取消订阅的函数。
- `useEditorState(...flags: boolean[])`: React Hook，用于将传入的布尔标志同步到全局状态。

## 核心实现说明

该文件的核心逻辑是维护一个计数器 `count`，用于跟踪编辑窗口的开启次数。`notify` 函数用于通知所有订阅者状态的变化。

- `open()` 和 `close()` 方法分别增加和减少计数器，并通过 `notify()` 函数通知所有订阅者。
- `get()` 方法返回当前计数器的值，用于判断编辑窗口是否开启。
- `subscribe()` 方法允许外部代码订阅状态变化，当状态变化时，所有订阅的函数都会被调用。

`useEditorState` Hook 允许 React 组件根据传入的布尔标志自动同步到全局状态。当标志为 `true` 时，编辑窗口将被视为开启。

该模块与项目其他模块的关系在于，它为项目提供了一个全局的状态管理机制，可以被任何需要跟踪编辑窗口状态的模块引用。

## 注意事项或使用方式

- 使用 `editorState.open()` 和 `editorState.close()` 方法来控制编辑窗口的开启和关闭。
- 使用 `editorState.subscribe()` 方法来订阅编辑窗口状态的变化。
- 在 React 组件中，使用 `useEditorState` Hook 来根据传入的布尔标志自动同步状态。
