# src/components/AttackEditor.tsx

## 功能概述

该文件定义了一个名为 `AttackEditor` 的 React 组件，用于编辑和创建角色攻击。该组件负责展示攻击的属性，如名称、攻击加值、伤害、伤害类型、射程等，并提供界面供用户输入或选择这些属性。它还支持从装备中抓取攻击数据，并自动计算攻击加值和伤害加值。

## 主要导出/接口

- **导出类型**:
  - `AttackEditorProps`: 组件接收的属性类型，包含攻击数据、武器列表、角色数据、保存和删除攻击的回调函数等。
  - `DAMAGE_TYPES`: 攻击伤害类型的常量数组。
  - `WEAPON_PROPERTIES`: 武器属性类型的常量数组。
- **导出函数**:
  - `buildSubtype`: 根据武器距离和类别构建武器子类型。
  - `parseSubtypeForUI`: 解析武器子类型为距离和类别。
  - `parseDamage`: 解析伤害字符串为伤害骰和伤害加值。
- **导出组件**:
  - `AttackEditor`: 攻击编辑器组件。
- **导出 Store/常量**:
  无。

## 核心实现说明

`AttackEditor` 组件的核心逻辑包括：

- 使用 `useState` 和 `useEffect` 管理组件的状态，如攻击数据、武器选择、自定义属性等。
- 使用 `useMemo` 缓存攻击加值和伤害加值预览，以优化性能。
- 提供从装备中抓取武器的功能，并自动填充攻击数据。
- 支持手动编辑攻击属性，并自动计算攻击加值和伤害加值。
- 提供保存和删除攻击的接口。

该组件与项目其他模块的关系：

- 与 `@/types/character` 模块交互，以获取角色和武器类型定义。
- 与 `@/lib/attackBonus` 模块交互，以计算攻击加值和伤害加值。

该组件被以下模块引用：

- 角色管理模块：用于创建和编辑角色攻击。
- 装备管理模块：用于从装备中抓取攻击数据。

## 注意事项或使用方式

- 组件接收 `attack`、`weapons`、`character`、`onSave`、`onDelete` 和 `onClose` 等属性。
- `attack` 属性为可选，用于编辑现有攻击。
- `weapons` 属性为可选，用于提供武器选择列表。
- `character` 属性为可选，用于计算攻击加值和伤害加值。
- `onSave` 回调函数用于保存攻击。
- `onDelete` 回调函数用于删除攻击（可选）。
- `onClose` 回调函数用于关闭编辑器。
