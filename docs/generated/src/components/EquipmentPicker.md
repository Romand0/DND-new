# src/components/EquipmentPicker.tsx

## 功能概述
该文件定义了一个名为 `EquipmentPicker` 的 React 组件，用于展示和管理装备选择器。该组件允许用户从装备库中选择装备，并支持搜索和筛选功能。它承担着从服务器获取装备数据、展示装备列表以及处理用户选择和关闭操作的职责。该组件的存在是为了提供一个用户友好的界面，让用户能够方便地选择和添加装备到游戏中。

## 主要导出/接口
- 类型：`EquipmentPickerProps`
  - `onSelect`: `(item: EquipmentItem) => void` - 用户选择装备时触发的回调函数。
  - `onClose`: `() => void` - 用户关闭选择器时触发的回调函数。

## 核心实现说明
- **关键逻辑**：组件通过 `useState` 和 `useEffect` 钩子管理状态，包括搜索查询、选择的分类、装备列表和加载状态。`useMemo` 钩子用于缓存过滤后的装备列表，以提高性能。
- **状态管理**：组件使用 `useState` 管理搜索查询、选择的分类、装备列表和加载状态。
- **与项目其他模块的关系**：组件通过 `fetchAllEquipments` 函数从 API 获取装备数据，该函数位于 `@/lib/api` 目录下。
- **被谁引用**：该组件可能被游戏的主界面或其他需要装备选择功能的页面引用。

## 注意事项或使用方式
- 调用 `EquipmentPicker` 组件时，需要提供 `onSelect` 和 `onClose` 回调函数，以便处理用户的选择和关闭操作。
- 使用该组件前，确保已经正确配置了 API 接口和相关的类型定义。
