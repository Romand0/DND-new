# src/components/combat/InitiativeRollDialog.tsx

## 功能概述
该文件定义了一个名为 `InitiativeRollDialog` 的 React 组件，用于展示先攻投掷对话框。该对话框允许用户输入 d20 投掷结果，并计算先攻总值。组件承担着用户界面交互的职责，为角色扮演游戏中的先攻投掷提供用户界面支持。

## 主要导出/接口
- **类型**：`Props`
  - `open`: `boolean` - 控制对话框是否显示
  - `selectedPc`: `Character | null` - 选中的角色对象，如果未选择则为 `null`
  - `d20Input`: `string` - 用户输入的 d20 投掷结果
  - `onD20Change`: `(v: string) => void` - 当 d20 输入值改变时触发的回调函数
  - `onConfirm`: `() => void` - 当用户确认投掷结果时触发的回调函数
  - `onClose`: `() => void` - 当用户关闭对话框时触发的回调函数

## 核心实现说明
该组件的核心逻辑包括：
- 接收传入的属性，包括对话框的显示状态、选中的角色、d20 输入值以及相关的回调函数。
- 计算角色的敏捷调整值和 d20 投掷结果的总和。
- 根据输入值的有效性显示先攻总值。
- 提供用户界面元素，包括角色名称、d20 输入框、先攻总值显示以及确认和取消按钮。

状态管理：
- 组件不直接管理状态，而是通过传入的属性和回调函数与父组件进行交互。

与项目其他模块的关系：
- 该组件依赖于 `character` 类型定义，用于获取角色的敏捷调整值。
- 组件的输出结果可能被其他模块用于更新游戏状态。

被谁引用：
- 该组件可能被游戏主界面或其他需要先攻投掷功能的模块引用。

## 注意事项或使用方式
- 调用 `InitiativeRollDialog` 组件时，需要传入 `open`、`selectedPc`、`d20Input`、`onD20Change`、`onConfirm` 和 `onClose` 属性。
- 确保 `selectedPc` 属性不为 `null`，否则组件将不显示。
- 用户可以通过输入框输入 d20 投掷结果，按 Enter 键确认或按 Escape 键关闭对话框。
- 确认按钮在先攻总值未计算时（即输入无效或未输入）将处于禁用状态。
