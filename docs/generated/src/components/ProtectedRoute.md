# src/components/ProtectedRoute.tsx

## 功能概述

`ProtectedRoute.tsx` 文件是用于 React 路由保护的一个组件。它的主要职责是确保只有认证用户（即已登录用户）才能访问特定的路由。此外，它还支持一个可选的权限检查，即是否需要管理员（DM）权限才能访问。该组件的存在是为了增强应用程序的安全性，防止未授权的用户访问敏感页面。

## 主要导出/接口

- 类型：`ProtectedRouteProps`
  - `children: React.ReactNode`: 路由保护组件内部需要渲染的子组件或元素。
  - `requireDM?: boolean`: 可选参数，默认为 `false`，表示是否需要管理员权限。

- 组件：`ProtectedRoute`
  - `useAuth`: 从 `AuthContext` 中获取认证状态。

## 核心实现说明

`ProtectedRoute` 组件首先通过 `useAuth` 钩子获取认证状态，包括是否已认证、是否为管理员以及认证是否正在进行中。根据这些状态，组件执行以下逻辑：

1. 如果认证状态正在加载，则显示加载中提示。
2. 如果用户未认证，则重定向到登录页面。
3. 如果需要管理员权限且用户不是管理员，则重定向到玩家端首页。
4. 如果用户已认证且有权限，则正常渲染子组件。

该组件与 `AuthContext` 密切相关，它依赖于上下文提供的认证状态。它被其他需要权限验证的路由组件引用，以确保只有授权用户才能访问。

## 注意事项或使用方式

- 使用 `ProtectedRoute` 组件时，需要将其包裹在需要保护的子路由组件中。
- 确保 `AuthContext` 已正确设置并包含必要的认证状态。
- 当 `requireDM` 属性为 `true` 时，只有管理员才能访问受保护的路由。
