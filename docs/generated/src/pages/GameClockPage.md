# src/pages/GameClockPage.tsx

## 功能概述
该文件 `GameClockPage.tsx` 是一个 React 组件，负责展示和管理游戏时间。它提供了一个用户界面，允许用户查看和调整游戏时间，以及与日历模块进行交互。该组件的存在是为了提供一个直观的方式来控制游戏时间，并允许用户与日历模块进行同步。

## 主要导出/接口
- **类型**: 无
- **函数**:
  - `addMinutes(m: number)`: 接受一个整数 `m`，将游戏时间增加 `m` 分钟。
  - `reset()`: 将游戏时间重置为 8:00。
  - `toggleLinked()`: 切换游戏时间与日历的链接状态。
- **组件**:
  - `GameClock`: 游戏时钟组件，用于显示和调整时间。
- **Store**:
  - `gameTimeStore`: 游戏时间存储，用于获取和设置游戏时间。
  - `calendarStore`: 日历存储，用于获取日历信息。
- **常量**:
  - 无

## 核心实现说明
该组件的核心逻辑包括：
- 使用 `useState` 和 `useEffect` 钩子来管理组件的状态和副作用。
- 从 `gameTimeStore` 和 `calendarStore` 中获取游戏时间和日历信息。
- 使用 `getTimeOfDay` 函数根据当前时间确定时间段。
- 提供时间调整按钮，允许用户增加或减少时间。
- 提供快速跳转到预设时间点的功能。
- 提供时间段说明，显示当前时间段及其颜色。

该组件与项目其他模块的关系：
- 与 `gameTimeStore` 和 `calendarStore` 进行交互，获取和设置数据。
- 通过 `Link` 组件与 `/calendar` 路由进行导航。

该组件被谁引用：
- 通常由路由配置文件引用，作为 `/game-clock` 路由的组件。

## 注意事项或使用方式
- 用户可以通过拖拽时钟组件的时针或分针来调整时间。
- 可以通过点击按钮来增加或减少时间，或重置时间为 8:00。
- 可以通过点击按钮来切换游戏时间与日历的链接状态。
- 如果链接状态为开启，则会在页面上显示当前日期和节日信息。
