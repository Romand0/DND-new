# src/pages/Register.tsx

## 功能概述

该文件 `Register.tsx` 是一个 React 组件，负责处理用户注册功能。它承担着收集用户输入信息（用户名、密码、确认密码、角色），验证信息，并通过 API 调用将信息发送到服务器进行注册。该组件的存在是为了提供一个用户友好的界面，让用户能够方便地注册账号。

## 主要导出/接口

- **类型**: `Register`
- **函数**:
  - `handleSubmit(e: React.FormEvent)`: 处理表单提交事件，包括数据验证、API 调用和状态更新。
- **组件**:
  - `Register`: 本身就是一个 React 组件。
- **Store**: 无
- **常量**: 无

## 核心实现说明

该组件的核心逻辑包括：

- 使用 `useState` 钩子管理表单状态，包括用户名、密码、确认密码、角色、错误信息和加载状态。
- 使用 `useNavigate` 钩子实现页面跳转。
- 使用 `useAuth` 钩子获取 `login` 方法，用于在注册成功后登录用户。
- 在 `handleSubmit` 函数中，首先进行密码一致性验证和密码长度验证。
- 通过 `fetch` API 向服务器发送注册请求，处理响应，并在成功后调用 `login` 方法登录用户，最后跳转到首页。

该组件与项目其他模块的关系：

- 与 `AuthContext` 上下文相关联，用于获取和更新认证状态。
- 与 `/api/auth/register` API 端点交互，用于处理注册请求。

该组件被 `AuthContext` 中的 `login` 方法引用。

## 注意事项或使用方式

- 用户在提交注册信息前，需要确保用户名至少包含 2 个字符，密码至少包含 6 个字符，且两次输入的密码一致。
- 注册过程中，如果发生错误，会在页面上显示错误信息。
- 注册成功后，用户将被自动登录并跳转到首页。
