# src/pages/Login.tsx

## 功能概述
该文件 `Login.tsx` 是一个 React 组件，负责处理用户登录逻辑。它提供了一个登录表单，用户可以输入用户名和密码进行登录。登录成功后，用户将被重定向到首页。该组件存在是为了提供一个用户界面，让用户能够通过表单提交登录请求。

## 主要导出/接口
- 类型：`Login: React.FC`
- 函数：
  - `handleSubmit(e: React.FormEvent)`: 处理登录表单的提交事件。
- 组件：
  - `Link`: 用于页面间的导航。
- Store：无
- 常量：无

## 核心实现说明
该组件的核心逻辑包括：
- 使用 `useState` 钩子管理表单输入状态（用户名、密码、错误信息、加载状态）。
- 使用 `useNavigate` 钩子进行页面跳转。
- 使用 `useAuth` 钩子获取和调用 `AuthContext` 中的 `login` 方法，该方法负责处理登录逻辑，包括发送请求到后端 API 并更新状态。
- 在 `handleSubmit` 函数中，通过 `fetch` 发送 POST 请求到 `/api/auth/login`，并处理响应。
- 如果登录成功，使用 `login` 方法更新状态并跳转到首页。
- 如果登录失败，设置错误信息并显示给用户。

该组件与项目其他模块的关系：
- 与 `AuthContext` 模块紧密相关，通过该模块管理用户认证状态。
- 与后端 API 进行交互，处理登录请求。

该组件被 `ProtectedRoute` 组件引用，用于保护需要认证的页面。

## 注意事项或使用方式
- 用户需要输入有效的用户名和密码才能提交登录表单。
- 登录过程中，如果发生错误，错误信息会显示在表单下方。
- 登录成功后，用户将被重定向到首页。
- 如果用户尚未注册，可以点击“注册”链接跳转到注册页面。
