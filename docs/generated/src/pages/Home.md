# src/pages/Home.tsx

## 功能概述

该文件定义了DM Toolkit项目的首页组件（Home），负责展示项目的主要功能和引导用户进入不同的模块。首页组件根据用户是否为地下城主（DM）显示不同的内容，并为DM和非DM用户提供不同的入口。

## 主要导出/接口

```typescript
export default function Home() {
  // ...
}
```

- `Home`：React函数组件，负责渲染首页内容。

## 核心实现说明

### 关键逻辑

- 组件使用`useState`和`useEffect`钩子来管理状态和副作用。
- `useState`用于创建`isDM`和`checking`状态，分别表示用户是否为DM和是否正在检查用户状态。
- `useEffect`用于在组件挂载时执行检查用户状态的逻辑，并在用户状态发生变化时更新`isDM`状态。
- 通过监听`storage`事件和自定义事件`dm-token-change`来实时更新用户状态。

### 状态管理

- `isDM`：布尔值，表示用户是否为DM。
- `checking`：布尔值，表示是否正在检查用户状态。

### 与项目其他模块的关系

- 首页组件通过`Link`组件与`react-router-dom`库集成，实现页面跳转。
- 首页组件通过`PlayerHome`组件展示非DM用户的内容。

### 被谁引用

- 该组件被项目的主入口文件引用，作为应用的首页。

## 注意事项或使用方式

- 组件在加载时会显示加载状态，直到用户状态被检查完成。
- 如果用户为DM，则显示DM模式下的首页内容，包括项目介绍、功能模块和安全性说明。
- 如果用户为非DM，则直接渲染`PlayerHome`组件。
- 用户可以通过点击“开始使用”按钮进入角色卡库模块。
