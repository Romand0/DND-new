# src/pages/Settings.tsx

## 功能概述

该文件定义了应用程序的设置页面（SettingsPage），负责展示和管理应用程序的各种配置选项。它作为用户界面的一部分，提供对管理员认证、账号管理、数据迁移和备份、数据管理等功能的访问。

## 主要导出/接口

- `SettingsPage`: 设置页面组件，负责渲染设置页面的UI。
  - `hasToken`: 布尔值，指示是否存储了有效的DM Token。
  - `isVerified`: 布尔值，指示DM Token是否已验证。
  - `isOnSubPage`: 布尔值，指示当前是否位于子页面（如管理员认证页面）。
  - `navigate`: 函数，用于导航到指定的路由。
  - `location`: 对象，包含当前路由的信息。

## 核心实现说明

`SettingsPage`组件首先使用`useNavigate`和`useLocation`钩子获取导航和位置信息。然后，它检查存储在`localStorage`中的`DM Token`是否存在以及是否已验证。根据这些信息，组件决定显示主页面还是子页面内容。

- **主页面**：展示一个导航栏，包含指向不同设置子页面的链接。
- **子页面**：通过`Outlet`组件渲染对应的子路由内容。
- **无Token提示**：当没有有效的DM Token时，显示一个提示，并引导用户前往管理员认证页面。
- **有Token时显示入口卡片**：当存在有效的DM Token时，显示三个功能入口卡片，分别指向账号一览、数据迁移与备份、数据管理页面。
- **Token已认证提示**：当DM Token已验证时，显示一个提示，告知用户拥有编辑权限。

## 注意事项或使用方式

- 该组件依赖于React Router库进行路由管理。
- 使用前需确保已正确配置React Router。
- 在渲染子页面时，需要确保相应的路由配置正确。
