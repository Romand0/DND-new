# src/pages/SpellDetail.tsx

## 功能概述

该文件 `SpellDetail.tsx` 是一个 React 组件，负责展示和管理单个法术的详细信息。它承担着展示法术的基本信息、描述、升环效果、备注、可用职业以及表格（如果存在）等职责。该组件的存在是为了提供一个直观且易于操作的单个法术详情页面。

## 主要导出/接口

- **`SpellDetail` 函数**：这是组件的主要导出，负责渲染单个法术的详情页面。
  - 无参数
  - 返回值：React 元素

## 核心实现说明

`SpellDetail` 组件的核心逻辑包括：

- 使用 `useParams` 和 `useNavigate` 钩子获取当前法术的 ID 和导航功能。
- 使用 `useAuth` 钩子获取当前用户的权限信息。
- 使用 `useState` 钩子管理法术数据、加载状态、错误信息、编辑器状态、删除确认状态和保存状态。
- 使用 `useEffect` 钩子在组件挂载时加载法术详情。
- 通过 `apiFetch` 函数从后端获取法术数据，并处理加载、保存和删除操作。
- 使用 `renderWithDice` 函数解析并渲染包含骰子符号的文本。
- 根据用户的权限展示编辑和删除按钮。
- 当用户点击编辑按钮时，显示 `SpellEditor` 模态框，允许编辑法术信息。
- 当用户点击删除按钮时，显示删除确认对话框。

该组件与项目其他模块的关系：

- 通过 `apiFetch` 与后端 API 交互。
- 通过 `SpellEditor` 组件与编辑功能交互。
- 通过 `AuthContext` 获取用户权限信息。

## 注意事项或使用方式

- 该组件应在 `/pages` 目录下使用，并确保 `apiFetch` 和 `AuthContext` 正确配置。
- 使用该组件时，需要传递一个有效的法术 ID。
- 组件会根据用户的权限显示不同的操作按钮。
