# src/pages/InventoryPage.tsx

## 功能概述
该文件 `InventoryPage.tsx` 是一个 React 组件，负责渲染物资钱币页面的 UI 结构。它承担着展示物资钱币页面内容、导航到相关子页面的职责。该页面存在是为了提供一个清晰的界面，让用户能够浏览和管理装备、交易以及宝藏。

## 主要导出/接口
该文件导出了一个默认导出的 React 函数组件 `InventoryPage`。

```typescript
export default function InventoryPage() {
  // 组件实现
}
```

## 核心实现说明
`InventoryPage` 组件使用 React 的 JSX 语法来构建页面布局。它包含一个标题和三个链接，分别对应装备库、交易板块和宝藏板块。每个链接都是一个 `Link` 组件，使用 `react-router-dom` 库来实现页面跳转。

- **装备库**：允许用户浏览和管理所有装备。
- **交易**：用户可以选择角色进行买入、卖出与物资分配。
- **宝藏**：用户可以创建和管理宝藏，手动分配给角色。

该组件通过 `Link` 组件与路由系统交互，实现页面跳转功能。它不直接管理状态，但可能依赖于父组件或上下文中的状态管理。

## 注意事项或使用方式
- 该组件应作为父组件使用，以提供上下文状态和路由。
- 使用前确保已正确配置 `react-router-dom` 和相关样式。
- 组件中的链接会触发页面跳转，因此应确保目标路由已正确设置。
