# src/pages/UserProfile.tsx

## 功能概述
该文件 `UserProfile.tsx` 是一个 React 组件，负责展示和编辑用户个人资料。它包含用户头像、用户名、权限类型、修改密码和退出登录等功能。该组件是用户个人中心的核心部分，为用户提供了一个交互式的界面来管理自己的账户信息。

## 主要导出/接口
- **导出类型**: `UserProfile`
- **函数**:
  - `compressImage(file: File): Promise<string>`: 将图片压缩到指定大小并返回 base64 数据 URL。
  - `openEdit()`: 打开编辑资料弹窗。
  - `onPickFile(file: File | undefined): Promise<void>`: 处理文件选择并压缩图片。
  - `submitEdit(): Promise<void>`: 提交编辑资料表单。
  - `submitPassword(): Promise<void>`: 提交修改密码表单。
  - `handleLogout(): Promise<void>`: 处理退出登录逻辑。
- **组件**:
  - `UserProfile`: 主组件，包含头像、用户名、权限类型、修改密码和退出登录等子组件。
- **Store**: 无
- **常量**:
  - `VERIFIED_KEY`: 用于存储用户是否验证过的键。
  - `MAX_AVATAR_SIZE`: 用户头像的最大尺寸。

## 核心实现说明
- **关键逻辑**: 该组件使用 React 的 `useState` 和 `useRef` 钩子来管理组件状态和引用。它通过调用 `api` 模块提供的函数来与后端进行交互，如上传头像、更新用户资料和修改密码。
- **状态管理**: 组件使用多个状态变量来跟踪用户输入、编辑状态、错误信息和加载状态。
- **与项目其他模块的关系**: 该组件依赖于 `api` 模块来与后端进行通信，以及 `AuthContext` 来获取和更新用户认证状态。
- **被谁引用**: 该组件被包含在项目的主路由中，通常在用户登录后显示。

## 注意事项或使用方式
- 用户需要登录后才能访问和编辑个人资料。
- 修改密码时，新密码长度至少为 6 位，且需要与确认密码一致。
- 用户可以通过点击头像或“编辑”按钮来打开编辑资料弹窗。
- 退出登录会清除本地存储的认证信息，并重定向到登录页面。
