# src/types/treasure.ts

## 功能概述
该文件定义了宝藏系统相关的类型，包括货币单位、价格、物品、货币、宝藏以及分配记录等。这些类型定义了宝藏系统中数据结构和接口，为后续的宝藏管理、分配等功能提供基础。

## 主要导出/接口
- `TreasurePriceUnit`: 货币单位类型，包含 'pp'（铂金币）、'gp'（金币）、'sp'（银币）、'cp'（铜币）。
- `TreasurePrice`: 价格接口，包含金额 `amount` 和货币单位 `unit`。
- `TreasureItem`: 物品接口，包含物品ID、名称、数量、单价、分类、子分类、重量和装备快照。
- `TreasureCurrency`: 货币接口，包含不同面值的货币数量。
- `Treasure`: 宝藏接口，包含宝藏ID、标题、货币、物品列表、创建时间和更新时间。
- `DistributionRecord`: 分配记录接口，包含宝藏ID、角色ID、角色名称、分配的货币和物品、分配时间。

## 核心实现说明
- 该文件定义了一系列接口，用于描述宝藏系统中涉及的数据结构。
- `TreasurePriceUnit` 和 `TreasureCurrency` 定义了货币单位和货币的表示方式，方便后续进行货币计算和转换。
- `TreasureItem` 接口详细描述了物品的属性，包括单价、分类、子分类等，为物品管理提供便利。
- `Treasure` 接口定义了宝藏的基本信息，包括货币和物品列表，为宝藏管理提供数据基础。
- `DistributionRecord` 接口记录了角色从宝藏中分到的物品和货币，为分配功能提供数据支持。
- 这些接口在项目中被多个模块引用，如宝藏管理模块、分配模块等。

## 注意事项或使用方式
- 使用 `TreasurePrice` 和 `TreasureCurrency` 进行货币计算和转换时，请注意货币单位的一致性。
- 在处理 `TreasureItem` 时，注意物品的分类和子分类，以便于后续的整理和管理。
- 在使用 `DistributionRecord` 时，确保记录的分配时间和分配物品的准确性。
