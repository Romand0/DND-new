# src/types/treasure.ts

## 功能概述
该文件定义了宝藏系统相关的类型，包括货币单位、宝藏物品、宝藏本身以及分配记录等。这些类型定义了宝藏系统的数据结构，为后续的代码实现和数据交互提供了基础。

## 主要导出/接口
- `TreasurePriceUnit`: 货币单位类型，包含铂金币、金币、银币、铜币等。
- `TreasurePrice`: 宝藏价格接口，包含金额和货币单位。
- `TreasureItem`: 宝藏物品接口，包含物品ID、名称、数量、单价、分类、子分类、重量和装备快照等。
- `TreasureCurrency`: 宝藏货币接口，包含铂金币、金币、银币、铜币的数量。
- `Treasure`: 宝藏接口，包含宝藏ID、标题、货币、物品列表、经验值奖励、创建时间和更新时间等。
- `DistributionRecord`: 分配记录接口，包含宝藏ID、角色ID、角色名称、分到的货币、分到的物品、分到的经验值和分配时间等。
