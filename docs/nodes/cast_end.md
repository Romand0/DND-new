# cast_end - 施法结束

## 功能概述

施法结束节点用于完成法术的收尾工作，包括清理施法状态、释放资源、触发结束事件等。这是法术流程的最终节点，确保法术的完整性和一致性。

## 状态
- ✅ **当前**：主要使用的施法结束节点
- 🔄 **重要性**：法术流程收尾的关键节点

## 配置项

| 字段 | 类型 | 必填 | 默认值 | 说明 |
|------|------|------|--------|------|
| `cleanupResources` | boolean | 否 | true | 是否清理资源 |
| `triggerEvents` | boolean | 否 | true | 是否触发结束事件 |
| `updateCooldowns` | boolean | 否 | true | 是否更新冷却时间 |
| `logResults` | boolean | 否 | true | 是否记录结果 |

## 详细配置说明

### cleanupResources - 是否清理资源
- **类型**：布尔值
- **必填**：否
- **默认值**：`true`
- **说明**：是否清理施法过程中使用的资源
- **规则**：清理法术位、动作点数等资源
- **用途**：确保资源的正确释放

### triggerEvents - 是否触发结束事件
- **类型**：布尔值
- **必填**：否
- **默认值**：`true`
- **说明**：是否触发法术结束事件
- **规则**：触发相关的结束事件
- **用途**：通知其他系统法术已结束

### updateCooldowns - 是否更新冷却时间
- **类型**：布尔值
- **必填**：否
- **默认值**：`true`
- **说明**：是否更新法术的冷却时间
- **规则**：减少法术的冷却时间
- **用途**：管理法术的冷却状态

### logResults - 是否记录结果
- **类型**：布尔值
- **必填**：否
- **默认值**：`true`
- **说明**：是否记录法术执行结果
- **规则**：记录法术的执行日志
- **用途**：提供法术执行的记录和追踪

## 输出数据

执行成功时返回：
```typescript
{
  status: 'success';
  output: {
    spellId: string;         // 法术ID
    casterId: string;        // 施法者ID
    cleanupCompleted: boolean; // 资源清理完成
    eventsTriggered: boolean; // 事件触发完成
    cooldownsUpdated: boolean; // 冷却时间更新完成
    resultsLogged: boolean;  // 结果记录完成
    message: string;         // 结束处理消息
    executionTime: number;   // 执行时间（毫秒）
    resources: {             // 清理的资源信息
      spellSlots: number;    // 清理的法术位数量
      actions: number;       // 清理的动作点数
      concentration: boolean; // 清理的专注状态
    };
    events: string[];        // 触发的事件列表
    cooldowns: {             // 冷却时间更新信息
      updated: string[];     // 更新的法术列表
      remaining: string[];   // 仍在冷却的法术列表
    };
  };
}
```

执行失败时返回：
```typescript
{
  status: 'failure';
  output: {
    error: string;           // 错误信息
    spellId: string;         // 法术ID
    casterId: string;        // 施法者ID
    failedSteps: string[];   // 失败的步骤
    partialCleanup: boolean; // 是否部分清理
  };
}
```

## 规则说明

- **专注管理**：持续法术需要施法者专注
- **冷却时间**：某些法术有冷却时间限制

- **法术位**：法术执行后消耗相应的法术位
- **动作点数**：法术执行消耗动作点数
- **专注状态**：持续法术占用施法者的专注
- **临时状态**：法术执行可能产生临时状态

### 事件触发规则
- **结束事件**：法术结束后触发相应的事件
- **状态通知**：通知其他系统法术已结束
- **效果清理**：清理相关的法术效果
- **状态更新**：更新相关的状态信息

### 冷却时间规则
- **冷却减少**：法术使用后进入冷却状态
- **冷却检查**：冷却时间结束后法术可重新使用
- **状态同步**：同步法术的冷却状态
- **通知系统**：通知系统法术冷却状态变化
